Classroom Live 사용법
====================

1. ClassroomLive.Extension.vsix를 한 번 설치합니다. Visual Studio 2019 이상을 지원합니다.
2. Visual Studio에서 공유할 솔루션을 엽니다.
3. ClassroomLive.exe를 실행합니다.
4. 처음 한 번 교수 화면에서 "방화벽 허용"을 누르고 관리자 권한 요청을 승인합니다.
5. 교수 화면에서 "시작"을 누릅니다.
6. Visual Studio에서 공유할 파일을 열고 도구 > Classroom Live > 현재 파일 공유를
   누릅니다. 교수 화면의 "OO.cs 공유" 버튼을 눌러도 같습니다.
7. "주소 복사"를 눌러 같은 와이파이의 학생들에게 전달합니다.
8. 학생은 주소로 접속한 뒤 원하는 파일을 직접 선택합니다.
   학생 화면 아래쪽 버튼으로 교수님이 보는 줄로 따라가거나, 코드 복사,
   줄바꿈, 글자 크기 조절을 할 수 있습니다.
9. 공유 해제는 같은 메뉴를 다시 누르거나 교수 화면의 ×를 누릅니다.
10. 수업이 끝나면 교수 화면의 "종료" 또는 도구 > Classroom Live > 종료를 누릅니다.

Visual Studio에서 할 수 있는 것
-------------------------------

설치하면 Classroom Live 툴바가 생깁니다. 안 보이면
보기 > 도구 모음 > Classroom Live 를 켜세요.

    [ 실행 ] [ 종료 ] [ 멈춤 ] | [ 공유 ] [ 숨김 ]

같은 명령이 도구 > Classroom Live 메뉴에도 있습니다.
교수 화면(브라우저)에서 할 수 있는 일과 같고,
어느 쪽에서 하든 0.6초 안에 서로 반영됩니다.

- 실행    : ClassroomLive.exe를 켭니다. 한 번은 직접 실행해 둬야 합니다.
- 종료    : 수업을 끝냅니다.
- 멈춤    : 갱신만 섭니다. 학생은 마지막 화면을 계속 봅니다. (멈춘 뒤에는 "시작")
- 공유    : 지금 열려 있는 파일을 학생에게 보여줍니다. (공유 중이면 "공유 해제")
- 숨김    : 학생 화면에서만 감춥니다. (숨긴 뒤에는 "다시 보이기")

버튼 글자는 상황에 따라 바뀌고, 지금 못 쓰는 버튼은 회색으로 보입니다.
호스트가 꺼져 있으면 "실행"만 켜집니다.

공유 해제와 숨김은 다릅니다.
공유 해제는 목록에서 빼므로 다시 공유해야 하고,
숨김은 목록에 둔 채 학생 화면에서만 감춰 언제든 되돌릴 수 있습니다.

허용되지 않는 파일에서 공유를 누르면 "추가할 수 없는 타입의 파일입니다"라고 알립니다.

단축키
------

기본 단축키는 없습니다. 필요하면 직접 지정하세요.
도구 > 옵션 > 환경 > 키보드에서 아래 이름으로 찾을 수 있습니다.

- ClassroomLive.TogglePause  (시작/멈춤)
- ClassroomLive.ToggleShare  (현재 파일 공유/해제)
- ClassroomLive.ToggleHide   (현재 파일 숨김/해제)

실행과 종료는 실수로 누르면 수업이 끊기므로 단축키를 지정할 수 없습니다.

처음 실행할 때 Windows 방화벽 알림이 나타나면 "개인 네트워크"만 허용하세요.

ClassroomLive.exe를 실행하면 창이 따로 뜨지 않고 브라우저에 교수 화면만 열립니다.
검은 명령 창은 없습니다. 문제가 생기면 안내 창이 대신 뜹니다.

교수 화면 탭을 실수로 닫았다면 브라우저에서 아래 주소를 다시 열면 됩니다.

    http://localhost:5050/host

교수 화면을 닫아둔 채 보고 있는 학생도 없으면 30분 뒤 저절로 종료됩니다.
켜둔 것을 잊어도 계속 떠 있지 않습니다.

Visual Studio가 연결되지 않을 때
-------------------------------

- Visual Studio 전체 IDE와 솔루션이 실행 중인지 확인하세요.
- Visual Studio 확장이 설치되어 있는지 확인하세요.
- ClassroomLive.exe를 먼저 실행해야 확장이 연결할 수 있습니다.
  확장은 호스트가 남기는 연결 정보를 읽어 포트를 자동으로 찾습니다.
- 호스트를 껐다 켜면 확장이 다시 붙기까지 몇 초 걸립니다.
- Visual Studio 2019, 2022, 2026을 지원합니다.
- Visual Studio Code는 지원하지 않습니다.

학생이 접속하지 못할 때
----------------------

- 교수 PC와 학생 기기가 같은 와이파이에 있어야 합니다.
- 교수 화면에서 "방화벽 허용"을 한 번 눌렀는지 확인하세요.
- 학교 와이파이가 기기 간 통신을 막아둔 경우에는 접속되지 않습니다.
  (공유기 설정의 "AP 격리" 또는 "클라이언트 격리")
- PIN을 여러 번 틀리면 해당 기기가 1분간 차단됩니다. 잠시 뒤 다시 시도하세요.

공유 안전장치
-------------

- Visual Studio가 텍스트로 열 수 있는 파일이면 무엇이든 공유할 수 있습니다.
  확장자 제한은 없습니다. Makefile, .gitignore, .go, .rs 전부 됩니다.
- 다만 아래는 자동으로 막습니다.
  · 솔루션 폴더 밖의 파일과 심볼릭 링크·정션을 거친 파일
  · .git, .vs, bin, obj, node_modules, .aws, .ssh 같은 빌드·도구·자격 증명 폴더
  · .env, appsettings, nuget.config, launchSettings.json, web.config,
    gradle.properties, *.tfvars, 인증서·개인키, *.user
  · 내용이 텍스트가 아닌 파일
  막힌 경우에는 왜 막혔는지 화면에 표시됩니다.
- 일반 코드에서 비밀번호·API 토큰·개인 키처럼 보이는 값을 찾으면 Visual Studio에
  확인창이 뜹니다. 내용을 확인한 뒤 "예"를 눌러야 그 파일이 공유됩니다.
- 학생은 파일을 수정하거나 업로드할 수 없습니다.
- 교수 화면에서 "시작"을 누르기 전에는 파일을 공유하지 않습니다.
- "멈춤"은 갱신만 세웁니다. 학생에게는 마지막 화면이 그대로 보입니다.
  필기할 시간을 줄 때 쓰세요. 멈춘 동안에는 교수님 커서 위치도 움직이지 않습니다.
- 잠깐 감추려면 "숨김"을 쓰세요. 목록에 남아 있어 바로 되돌릴 수 있습니다.
- 목록에서 아예 빼려면 교수 화면의 × 버튼을 누르세요.
  다시 보여주려면 그 파일에서 공유를 한 번 더 누르면 됩니다.

주의
----

- 통신은 암호화되지 않습니다. 같은 와이파이에서 트래픽을 들여다볼 수 있는 사람은
  공유 중인 코드를 볼 수 있습니다. 민감한 코드는 공유하지 마세요.
