Classroom Live 사용법
====================

1. ClassroomLive.Extension.vsix를 한 번 설치합니다. Visual Studio 2019 이상을 지원합니다.
2. Visual Studio에서 공유할 솔루션을 엽니다.
3. ClassroomLive.exe를 실행합니다.
4. 처음 한 번 교수 화면에서 "방화벽 허용"을 누르고 관리자 권한 요청을 승인합니다.
5. 교수 화면에서 "방송 시작"을 누릅니다.
6. Visual Studio에서 공유할 파일을 선택하고 Ctrl+Alt+L을 누릅니다.
   도구 > Classroom Live: 현재 파일 공유/해제 메뉴를 눌러도 됩니다.
7. "학생 주소 복사"를 눌러 같은 와이파이의 학생들에게 전달합니다.
8. 학생은 주소로 접속한 뒤 원하는 파일을 직접 선택합니다.
9. 공유 해제는 해당 파일에서 Ctrl+Alt+L을 다시 누르거나 교수 화면의 ×를 누릅니다.
10. 수업이 끝나면 실행 중인 검은 창에서 Ctrl+C를 누르거나 창을 닫습니다.

처음 실행할 때 Windows 방화벽 알림이 나타나면 "개인 네트워크"만 허용하세요.

Visual Studio가 연결되지 않을 때
-------------------------------

- Visual Studio 전체 IDE와 솔루션이 실행 중인지 확인하세요.
- Visual Studio 확장이 설치되어 있는지 확인하세요.
- 호스트는 기본 포트 5050에서 실행되어야 합니다.
- Visual Studio 2019, 2022, 2026을 지원합니다.
- Visual Studio Code는 지원하지 않습니다.

공유 안전장치
-------------

- 현재 솔루션 폴더 안의 텍스트 코드 파일만 공유합니다.
- .env, appsettings, secrets, .git, .vs, bin, obj, node_modules는 자동 차단합니다.
- 학생은 파일을 수정하거나 업로드할 수 없습니다.
- 교수 화면에서 방송을 시작하기 전에는 파일을 공유하지 않습니다.
- 교수 화면의 파일 삭제 버튼은 현재 공유 목록에서 파일을 숨깁니다.
  다시 공유하려면 해당 파일에서 Ctrl+Alt+L을 한 번 누르세요.
